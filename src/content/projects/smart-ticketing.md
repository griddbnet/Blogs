# Smart Public Transport Ticketing System

## Inspiration
I was traveling in a bus while I got an idea: what if we make it more seamless via RFID?

## What it does
Each passenger must have an RFID card with them, which can be issued at each bus stop via a single person or a vending machine. Each time a person boards a bus, the sensor will detect it and will use long-range RFID to charge that person. If that person doesn't have a valid ticket, it should be informed to the respective authority.

## How we built it
Using long-range RFID, camera, and cloud, we track a person boarding and lodging the bus, calculate the distance traveled, and then deduct charges accordingly.

## Challenges we ran into
Finding a good sensor, microprocessor, and a reliable cloud service.

## Accomplishments that we're proud of
Making India smarter.

## What we learned
RFID technology.

## What's next for Smart public transport ticketing system
Using facial recognition for extreme automation.
