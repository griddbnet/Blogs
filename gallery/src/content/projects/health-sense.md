## The Project

This project is a HealthSense Predictive Monitoring system designed to track and analyze real-time patient vitals such as heart rate, oxygen saturation, body temperature, and blood pressure. The dashboard provides a clear and interactive interface that displays ECG waveforms, active alerts, and patient insights to help medical professionals make timely decisions. By combining data visualization with predictive analytics, the system improves patient safety, enables early detection of abnormalities, and supports efficient healthcare monitoring.
